# SkillSync

SkillSync is a full-stack MERN application that helps students find suitable teammates for projects, hackathons, and internships. The platform matches users based on technical skills, interests, and project requirements, making collaboration easier and more effective.

## Features

- Secure user authentication with JWT and bcrypt
- Create and manage student profiles
- Skill and interest-based teammate recommendations
- Project creation and management
- Advanced profile search and filtering
- Role-based authorization
- Responsive user interface
- MongoDB query optimization using indexing

## Tech Stack

- React
- Tailwind CSS
- Node.js
- Express.js
- MongoDB
- JWT
- bcrypt
